Quick start

  1. Update nuclei templatesRuns automatically on first start. Repeat whenever a CVE drops.
  2. Run an nmap scanTop 1000 ports, all ports or a custom range. Results land in the inventory.
  3. Review the inventoryFilter by product and version, select hosts, then hand them to nuclei.
  4. Run nucleiSearch templates by id, tag or CVE (for example CVE-2026-109619), pick one or many.
  5. React to a new 0-dayStart a campaign from the CVE: intel, a version rule and templates in one step.
  6. Triage issuesAssign owners, track SLAs and verify fixes with a re-scan.
