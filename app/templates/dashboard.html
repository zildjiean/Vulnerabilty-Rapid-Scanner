Quick start

  1. Updates → "Update nuclei templates" (first run only, then whenever a CVE drops).
  2. Nmap → scan a network (top ports or all ports). Results land in Inventory.
  3. Inventory → filter by product/version, select hosts, "Scan selected with nuclei".
  4. Nuclei → search templates (e.g. CVE-2026-109619), pick one or many, start.
  5. New 0-day without a template? Add a version rule or upload / pull a custom template.
